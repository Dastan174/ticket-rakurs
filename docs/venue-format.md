# Формат площадки

Площадка описывается одним JSON-объектом (`venue_layouts.params`, тип `VenueLayout` в `src/lib/venue/types.ts`). Из него строятся список мест, 3D-сцена и (позже) 2D-схема. Моделировать зал вручную не нужно.

Пример — `src/data/demo.ts` (`LAYOUTS.arena`, `LAYOUTS.stadium`).

## Поля

| Поле | Тип | Смысл |
|---|---|---|
| `name` | string | Название для интерфейса |
| `kind` | `"concert"` \| `"football"` | Влияет на декор: поле с разметкой у football |
| `night` | boolean | Тёмная сцена и цветной свет (концерт в помещении) |
| `bowl.rx`, `bowl.rz` | м | Полуоси эллипса партера/поля |
| `bowl.rows` | число | Рядов на трибуне |
| `bowl.depth`, `bowl.rise` | м | Глубина ряда и высота ступени |
| `bowl.base` | м | Высота первого ряда над полом |
| `bowl.a0`, `bowl.a1` | рад | Дуга трибун. `−π…π` — по кругу; меньше — подкова (за сценой нет мест) |
| `bowl.sectors` | число | Секторов на дуге, между ними проходы |
| `bowl.spacing` | м | Шаг кресел в ряду |
| `focus` | [x, y, z] | Куда смотрит зритель, севший на место (центр сцены или поля) |
| `overview` | `{pos, target}` | Начальная камера обзора |
| `stage` | `{x0, x1, halfZ, height}` | Сцена: по ней можно ходить |
| `screen` | `{pos, size}` | Экран на сцене, показывает название события |
| `boxes` | `[{size, pos, color}]` | Препятствия и декор: колонны, порталы, ферма, ворота |
| `zones` | правило | Как места делятся на ценовые зоны (см. ниже) |
| `colors` | `{sky, bowl, floor}` | Цвета фона, трибун, пола |

Координаты: `y` — вверх, центр партера в `(0, 0, 0)`, метры.

### Правила зон

- `{ by: "distance", origin: [x, z], thresholds: [18, 32] }` — по расстоянию до точки (обычно сцена): ближе 18 м — зона 0, ближе 32 м — зона 1, дальше — зона 2.
- `{ by: "sideline", strong: 0.8, strongRows: 12, mid: 0.5 }` — для стадиона: центральные трибуны вдоль поля дороже.

На реальном событии зоны задаёт организатор (`price_zones` + `event_seats.zone_id`), правило из площадки — только значение по умолчанию.

## Генерация мест

`generateSeats(layout)` идёт по секторам → рядам → местам и возвращает места в **стабильном порядке**. При загрузке площадки в БД места вставляются в этом порядке. Если генерация меняется, создаётся **новая версия** площадки (`venue_layouts.version + 1`), старые события остаются на старой.

`groundHeight(layout, x, z)` — высота пола для ходьбы: 0 в партере, высота сцены на сцене, ступень ряда на трибуне, `null` — стена.

## Как завести новую площадку

1. По чертежу или замерам подобрать `bowl` (ряды, ступень, шаг кресел) и дугу.
2. Расставить `boxes`: всё, что может закрывать обзор.
3. Проверить в 3D: сесть на крайние места и последний ряд, сверить с фото с 3–5 точек.
4. Добавить тест на число мест в `tests/venue.test.ts`, если площадка эталонная.
