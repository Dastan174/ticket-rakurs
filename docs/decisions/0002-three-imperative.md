# 0002. Three.js императивно, без react-three-fiber

**Статус:** принято, 23.11.2026

## Контекст

В ТЗ был указан react-three-fiber. Рабочий прототип (`docs/product/prototype.html`) написан на чистом Three.js: обзор, перелёт камеры, ходьба по ступеням, перекраска тысяч кресел.

## Решение

Перенести прототип как есть в один клиентский компонент `VenueViewer`: сцена создаётся в `useEffect`, React управляет только пропсами (места, статусы, выбор, режим «на месте»). Чистая логика (места, высота пола) вынесена в `src/lib/venue/`.

## Почему

- Ноль переписывания: прототип уже проверен.
- Меньше зависимостей и меньше бандл (нет r3f и drei).
- Вся сцена — это один `InstancedMesh` и пара мешей, декларативное дерево React тут почти ничего не даёт.

## Когда пересмотреть

Если появится много интерактивных 3D-объектов со своим состоянием (редактор площадки на этапе 2) — редактор можно сделать на r3f отдельно, не трогая `VenueViewer`.
