# 0001. Стек: Next.js + Supabase + Cloudflare, без своего бэкенда

**Статус:** принято, 23.11.2026

## Контекст

Команда — 2 человека, бюджет инфраструктуры ≈ $30–45 в месяц, нужен MVP за ~4 месяца. Критичная часть — бронь без двойных продаж и пики при старте продаж.

## Решение

- **Next.js 16** на **Cloudflare Workers** (OpenNext): SEO через серверный рендер, хостинг ≈ $5, CDN из коробки. Vercel отклонён: бесплатный план запрещает коммерцию, Pro — $20 за участника.
- **Supabase** вместо своего NestJS-сервера: Postgres, вход, Realtime, pg_cron и Edge Functions одной услугой за $25. Бронь — SQL-функции в базе.
- **Cloudflare R2** для 3D-сцен и картинок: бесплатный исходящий трафик (у Supabase Storage платный сверх 250 ГБ).
- **Upstash Redis** — только для виртуальной очереди на этапе 3.

## Последствия

- Меньше кода и серверов, но часть логики живёт в SQL — её покрываем тестами на PGlite.
- Привязка к Supabase умеренная: это обычный Postgres, можно переехать на свой сервер.
- Realtime ограничен тарифом (500 подключений на Pro, дальше $10 за тысячу) — учтено в расчёте стоимости.
