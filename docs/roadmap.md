# План работ

Команда — 2 человека: **Первый** — сайт, 3D, интерфейс; **Второй** — Supabase, бронь, кабинеты, сканер, нагрузка. MVP ≈ 4 месяца. Полное описание — [ТЗ, раздел 10](product/tz.html).

## Этап 0 — подготовка (1 неделя)

- [x] Next.js 16 + Tailwind + TypeScript, конфиг Cloudflare (OpenNext, wrangler)
- [x] Supabase: схема, RLS, функции брони `hold_seats` / `cancel_order` / `confirm_payment` / `expire_holds`
- [x] SQL-тесты брони на PGlite
- [x] Формат площадки `VenueLayout`, генерация мест, высота пола + тесты
- [x] 3D-зал перенесён из прототипа в компонент `VenueViewer`
- [x] Документация и правила для ИИ-агентов
- [ ] Создать проект Supabase и Cloudflare, первый деплой (см. [deployment.md](deployment.md))
- [ ] Макеты ключевых экранов на shadcn/ui
