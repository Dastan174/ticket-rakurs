# Дополнительно для Claude Code

## Субагенты проекта (`.claude/agents/`)

| Агент | Когда звать |
|---|---|
| `supabase-db` | Новая таблица, миграция, RLS-политика, SQL-функция |
| `booking-reviewer` | Любое изменение брони, заказов, оплаты, `event_seats` — ревью перед коммитом |
| `venue-3d` | Изменения 3D-зала, формата площадки, генерации мест, производительности сцены |
| `frontend-ui` | Страницы и компоненты Next.js 16, Tailwind, доступность, мобильная вёрстка |

Изменение брони без прогона `booking-reviewer` не считается законченным.

## Как работать

- Перед кодом на Next.js — прочитать нужный раздел `node_modules/next/dist/docs/`.
- Перед изменением схемы — прочитать `docs/database.md` и текущие миграции.
- Проверка в браузере: `npm run dev`, страница события `/events/cup-final`. 3D не анимируется в скрытой вкладке — открой панель браузера.
- Не запускать `npm run deploy` и не применять миграции к удалённому Supabase без явной просьбы.
